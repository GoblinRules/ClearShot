# ClearShot v1.0.5

## Improvements

- Replaced emoji and symbol glyphs in the tray menu, annotation toolbar, selection overlay, and settings window with consistent vector-drawn Qt icons.
- Updated action buttons for copy, save, quick save, close, undo, redo, clear, text commit, text cancel, move, and resize controls.
- Updated app icon loading so ClearShot prefers the bundled `.ico` assets first, ensuring the refreshed main icon is used by windows and the system tray.
- Bundled the refreshed application icon assets and removed the old generated icon pack.
