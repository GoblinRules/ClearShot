# ClearShot v1.3.1

## Fixed

- Prevented the recording border and REC timer badge from appearing in saved recordings.
- Fixed live recording annotations so the toolbar can select tools and the drawing surface accepts pen, arrow, shape, text, and counter input.
- Changed live recording annotations to be composited into video frames directly, so the annotation toolbar itself is not recorded.
- Fixed overlay layering so the recording border no longer sits above the annotation drawing surface.
